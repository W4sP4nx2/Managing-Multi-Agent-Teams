# Instructor delivery schedule

Private facilitation reference. Learner navigation uses competency order without delivery dates or durations. The historical classroom schedule below is retained for planning. Integrate the factory and local CI/CD rehearsals into the delivery allocation rather than presenting them as an end-of-course bonus.



The [course syllabus](../assignments/assignment_syllabus.md) groups nine competency topics into the sessions below. One main 26-slide presentation supports the entire route. Procurement and HR/RAG are formative walkthroughs, not additional graded implementations. The practical sequence contains one preflight, three labs, one software Capstone, and the integrated factory and local CI/CD labs.

## Integrated factory facilitation

Use the [five-minute demonstration script](demo_script.md) during the factory block. The paced terminal run uses deterministic outputs, actual local files and Git operations, six explicit human approvals, and simulated costs; actual API cost is $0.00. No API keys or provider setup are required. Inspect the evidence before each decision and identify local publication accurately. The notebook rehearsals use clearly labeled fixture decisions rather than human approval.
