# Course Resources

Use the [curated course resource library](curated_resource_library.md) for academic and technical reading paired with the current course. Reading these references adds no assessment task or package requirement.

For the presentation's framework-literacy discussion, open the [multi-agent framework comparison](framework_comparison.md): four core patterns, a broader ecosystem table, and production decision starting points. It is slides/reference reading only; it adds no exercise or installation.

For the required exercises, return to the [learner dashboard](../README.md#click-through-course-journey) or [assignment index](../assignments/index.md).

Supporting files are grouped by type:

- [`papers/`](papers/README.md): guidance for adding locally stored papers; this directory currently contains no paper PDFs.
- [`videos/`](videos/README.md): transcripts and timestamps.
- [`cited_resources/`](cited_resources/README.md): optional design fixtures for advanced homework. The required labs and Capstone do not load these files.

The core exercises remain local and deterministic; these resources are optional reading.
