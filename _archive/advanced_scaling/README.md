# Archived Advanced Scaling Material

This folder contains cross-organization A2A material and network-boundary exercises kept for optional advanced study. None of it is part of the two-day learner path or a Capstone prerequisite.

- [Enterprise A2A perimeter notebook](notebooks/11_enterprise_a2a_perimeter.ipynb): network-boundary identity, schema, and dead-letter exercises.
- [Trust and governance matrix](assignments/ex4_trust_governance_matrix.md): external HR/vendor team scenario and policy rubric.
- [A2A OpenAPI contract](assignments/a2a_openapi_contract.md): third-party Security Agent REST contract.
- [A2A identity and tool matrix](instructor/a2a_identity_tool_matrix.md): legacy identity/tool reference across separate organization scenarios.
- [Adversarial QA A2A exercise](assignments/adversarial_qa_a2a.md): external red-team payload and quarantine exercise.
- [Historical starter and solution code](assignments/starter_code/): the FastAPI Capstone solution, A2A governance starter/solution, and MCP governance wrapper. These require their own review and optional dependencies; the core course does not import them.

The Capstone's Development-Team-to-Security-Team Pydantic contract is an internal workflow handoff. It does not use or require the archived cross-organization transport patterns.
